# Color Schema Reference

Gaia UI uses a two-stage color architecture:
1. **`schemaColor.json`** — The high-level color configuration where you define your brand identity, neutral scale, and semantic states.
2. **`schemaColor.css`** — The compiled stylesheet generated by `gaia theme-gen`, containing Tailwind CSS v4 `@theme` tokens mapped to functional UI roles (surfaces, text, borders, buttons, and gradients).

---

## 1. Color Schema Configuration (`schemaColor.json`)

The `schemaColor.json` file is the central source of truth for your color scheme. It is divided into three key groups: **Brand**, **Neutral**, and **Semantic**.

```json title="schemaColor.json"
{
  "brand": {
    "primary": "Hex/RGB - Primary action buttons, headers, & active links",
    "primaryDark": "Hex/RGB - Hover/pressed states for primary buttons",
    "primaryLight": "Hex/RGB - Soft badge backgrounds, highlights, & selection states",
    "secondary": "Hex/RGB - Secondary action buttons, graphic accents, & category badges",
    "accent": "Hex/RGB - Call-to-Action (CTA) buttons, promos, & high-priority highlights"
  },
  "neutral": {
    "0": "Hex/RGB - Pure white: card backgrounds, modals, & input fields",
    "50": "Hex/RGB - Main page background canvas",
    "100": "Hex/RGB - List row hover states, soft dividers, & subtle section backgrounds",
    "200": "Hex/RGB - Component borders, input outlines, & container frames",
    "400": "Hex/RGB - Muted text, placeholder text, & disabled icons",
    "600": "Hex/RGB - Subheadings, input labels, & secondary body text",
    "800": "Hex/RGB - Primary body text & high-contrast elements",
    "900": "Hex/RGB - Main page titles, heavy headings, & maximum emphasis text"
  },
  "semantic": {
    "success": "Hex/RGB - Success messages, active status badges, & positive indicators",
    "warning": "Hex/RGB - Warning alerts, pending status, & caution indicators",
    "danger": "Hex/RGB - Error messages, destructive actions (delete/cancel), & failures",
    "info": "Hex/RGB - Informational banners, technical hints, & general notices"
  }
}
```

### Functional Role Breakdown

| Token Key | Role & UI Application | Typical Usage |
| :--- | :--- | :--- |
| **`brand.primary`** | Core brand identity | Primary buttons, active navigation items, key action links |
| **`brand.primaryDark`** | Deep contrast shade | Hover & active states for primary action elements |
| **`brand.primaryLight`** | Light brand tint | Subtle selection rings, active list item backgrounds, badge pills |
| **`brand.secondary`** | Supporting contrast | Secondary action triggers, category tags, decorative vectors |
| **`brand.accent`** | High-energy highlight | Urgent CTA buttons, conversion banners, animated glow highlights |
| **`neutral.0`** | Clean base surface | Modal dialogs, popovers, card surfaces, and input containers |
| **`neutral.50`** | Canvas background | The default root background of the entire viewport |
| **`neutral.100`** | Subtle layer background | Alternate table rows, section backdrops, subtle dividers |
| **`neutral.200`** | Boundary definition | Card borders, table headers, and form field frames |
| **`neutral.400`** | De-emphasized text | Input placeholders, helper text, and inactive icons |
| **`neutral.600`** | Readable body copy | Standard content text, paragraphs, and descriptions |
| **`neutral.800`** | High-contrast copy | Bold emphasis text, data metrics, and subheadings |
| **`neutral.900`** | Maximum contrast | Main page titles, modal titles, and inverse dark surfaces |
| **`semantic.success`** | Positive status | Confirmation badges, success toasts, verified indicators |
| **`semantic.warning`** | Warning status | Attention alerts, pending review pills, caution notifications |
| **`semantic.danger`** | Destructive status | Error validation messages, delete buttons, critical toasts |
| **`semantic.info`** | Neutral informational | Help tooltips, documentation alerts, technical hints |

## 2. Generated CSS Tokens (`schemaColor.css`)

When you run `gaia theme-gen`, the CLI processes your JSON configuration and compiles it into design tokens inside a Tailwind CSS v4 `@theme` block.

Rather than hardcoded hex values, each variable represents a functional design token. Below is the full mapping of how the generated variables are constructed:

```css title="schemaColor.css"
@theme {
  /* ------------------------------------------------------------------
     1. Brand Palette Tokens
     ------------------------------------------------------------------ */
  --color-palette-brand-primary: /* Core brand color (from brand.primary) */;
  --color-palette-brand-primary-dark: /* Hover & active shade (from brand.primaryDark) */;
  --color-palette-brand-primary-light: /* Soft tint background (from brand.primaryLight) */;
  --color-palette-brand-secondary: /* Secondary supporting brand color (from brand.secondary) */;
  --color-palette-brand-accent: /* High-visibility CTA highlight (from brand.accent) */;

  /* ------------------------------------------------------------------
     2. Neutral Scale Tokens
     ------------------------------------------------------------------ */
  --color-palette-neutral-0: /* Pure surface background (from neutral.0) */;
  --color-palette-neutral-50: /* Viewport background canvas (from neutral.50) */;
  --color-palette-neutral-100: /* Subtle section background (from neutral.100) */;
  --color-palette-neutral-200: /* Component borders and divider lines (from neutral.200) */;
  --color-palette-neutral-400: /* Subdued text, placeholders, & icons (from neutral.400) */;
  --color-palette-neutral-600: /* Secondary body copy (from neutral.600) */;
  --color-palette-neutral-800: /* High-contrast body typography (from neutral.800) */;
  --color-palette-neutral-900: /* Deep heading color & inverse dark fill (from neutral.900) */;
  --color-palette-neutral-overlay: /* Translucent backdrop overlay (derived from neutral.900) */;

  /* ------------------------------------------------------------------
     3. Semantic Status Tokens
     ------------------------------------------------------------------ */
  --color-palette-semantic-success: /* Positive alert & status indicator (from semantic.success) */;
  --color-palette-semantic-warning: /* Cautionary warning indicator (from semantic.warning) */;
  --color-palette-semantic-danger: /* Error alert & destructive indicator (from semantic.danger) */;
  --color-palette-semantic-info: /* Informational badge & hint indicator (from semantic.info) */;

  /* ------------------------------------------------------------------
     4. Functional Page Surfaces & Backgrounds
     ------------------------------------------------------------------ */
  --color-background-page: /* Root page background canvas (maps to neutral-50) */;
  --color-background-section: /* Secondary section background (maps to neutral-100) */;
  --color-background-inverse: /* High-contrast inverted dark background (maps to neutral-900) */;

  /* ------------------------------------------------------------------
     5. Containers, Cards & Modals
     ------------------------------------------------------------------ */
  --color-container-card-bg: /* Card surface background (maps to neutral-0) */;
  --color-container-card-border: /* Card perimeter border (maps to neutral-200) */;
  --color-container-card-hover-bg: /* Card hover surface state (maps to neutral-50) */;
  --color-container-modal-bg: /* Modal dialog backdrop surface (maps to neutral-0) */;
  --color-container-modal-border: /* Modal dialog border outline (maps to neutral-200) */;
  --color-container-subtle-box-bg: /* Soft accent box surface (maps to brand-primary-light) */;
  --color-container-subtle-box-border: /* Soft accent box border (maps to brand-primary) */;

  /* ------------------------------------------------------------------
     6. Typography Tokens
     ------------------------------------------------------------------ */
  --color-text-heading: /* Main titles and headings (maps to neutral-900) */;
  --color-text-body: /* Main paragraph and content text (maps to neutral-600) */;
  --color-text-muted: /* Subdued labels, captions, & placeholders (maps to neutral-400) */;
  --color-text-link: /* Interactive links and anchors (maps to brand-primary) */;
  --color-text-on-primary: /* Text color rendered over primary background (maps to neutral-0) */;
  --color-text-on-inverse: /* Text color rendered over inverse background (maps to neutral-50) */;

  /* ------------------------------------------------------------------
     7. Interactive Buttons
     ------------------------------------------------------------------ */
  --color-button-primary-bg: /* Primary button fill (maps to brand-primary) */;
  --color-button-primary-bg-hover: /* Primary button hover state (maps to brand-primary-dark) */;
  --color-button-primary-text: /* Primary button text label (maps to neutral-0) */;
  --color-button-secondary-bg: /* Secondary button fill (maps to neutral-100) */;
  --color-button-secondary-bg-hover: /* Secondary button hover state (maps to neutral-200) */;
  --color-button-secondary-text: /* Secondary button text label (maps to neutral-900) */;
  --color-button-secondary-border: /* Secondary button outline (maps to neutral-200) */;
  --color-button-outline-bg-hover: /* Outline button hover fill (maps to brand-primary-light) */;
  --color-button-outline-text: /* Outline button text label (maps to brand-primary) */;
  --color-button-outline-border: /* Outline button border outline (maps to brand-primary) */;
  --color-button-danger-bg: /* Destructive action button fill (maps to semantic-danger) */;
  --color-button-danger-text: /* Destructive button text label (maps to neutral-0) */;
  --color-button-disabled-bg: /* Disabled button surface (maps to neutral-200) */;
  --color-button-disabled-text: /* Disabled button text label (maps to neutral-400) */;

  /* ------------------------------------------------------------------
     8. Form Inputs
     ------------------------------------------------------------------ */
  --color-input-bg: /* Input field background surface (maps to neutral-0) */;
  --color-input-text: /* Input typed text color (maps to neutral-900) */;
  --color-input-placeholder: /* Input placeholder label (maps to neutral-400) */;
  --color-input-border: /* Default input border outline (maps to neutral-200) */;
  --color-input-border-focus: /* Focused input outline (maps to brand-primary) */;
  --color-input-border-error: /* Invalid input validation border (maps to semantic-danger) */;

  /* ------------------------------------------------------------------
     9. Linear Gradient Tokens
     ------------------------------------------------------------------ */
  --background-image-brand-hero: /* Linear gradient: brand-primary -> brand-secondary -> brand-accent */;
  --background-image-brand-hero-inverse: /* Inverted direction of the hero gradient */;
  --background-image-button-cta: /* High-energy gradient for primary CTA actions */;
  --background-image-button-cta-inverse: /* Inverted CTA gradient for secondary triggers */;
  --background-image-button-secondary: /* Subtle surface gradient for secondary actions */;
  --background-image-secondary-accent: /* High-contrast accent gradient for banners and cards */;
  --background-image-container-surface-glow: /* Radiant top-to-bottom surface highlight gradient */;
  --background-image-container-surface-inverse: /* Dark inverted surface gradient for footer or dark sections */;
}
```
