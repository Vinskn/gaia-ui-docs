# Theme Configuration

Gaia UI provides an interactive CLI suite to manage design themes. You can pick from built-in presets or define a fully customized color scheme tailored to your brand.

---

## 1. Base Setup & CLI Commands

Once your premium license has been activated, you have access to the `gaia theme` commands.

### 1.1 View Available Presets (`theme list`)

To see the list of all pre-configured theme presets bundled with Gaia UI, run:

<Tabs groupId="package-manager">
  <TabItem value="bun" label="Bun" default>

```bash
bunx gaia theme list
```

  </TabItem>
  <TabItem value="npm" label="npm">

```bash
npx gaia theme list
```

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

```bash
pnpm dlx gaia theme list
```

  </TabItem>
  <TabItem value="yarn" label="Yarn">

```bash
yarn dlx gaia theme list
```

  </TabItem>
</Tabs>

**Available Built-in Presets:**
- **`vert`** *(Default)* — Fresh aurora emerald and neon accents; ideal for wellness, clean tech, and modern applications.
- **`noir`** — Deep black paired with warm gold/bronze; tailored for luxury and fintech.
- **`crimson`** — Modern punchy red with balanced contrast; great for creative studios and startups.
- **`raphtalia`** — Warm sunset orange with high energy; designed for gaming and media.
- **`rimuru`** — Tech-forward blue and violet with cyan accents; suited for AI platforms and developer tooling.

### 1.3 Automated Imports in `index.css` & `@source`

Whenever a theme is applied or generated, the CLI automatically updates your main stylesheet (`index.css`):

```css title="src/index.css"
@import "tailwindcss";
@import "./anima/config/schemacolor.css";
@source "../node_modules/@navatech/gaia-ui";

/* ========================================================
   Add your custom styling or overrides BELOW these lines.
   ======================================================== */
```

:::warning DO NOT MODIFY AUTOMATED IMPORTS
- **Do not alter or delete** the `@import "./anima/config/schemacolor.css";` and `@source "../node_modules/@navatech/gaia-ui";` statements.
- The `@source` directive tells Tailwind CSS v4 where to scan for Gaia UI utility classes.
- Any manual styles, extra fonts, or custom overrides must always be placed **below** these lines.
:::

## 2. Creating a Custom Theme

If your project requires a custom visual identity, you can define your own color scheme using a JSON configuration file and compile it into CSS tokens.

### Step 1: Initialize the Theme Configuration (`theme`)

Run the base theme command to scaffold your configuration file:

<Tabs groupId="package-manager">
  <TabItem value="bun" label="Bun" default>

```bash
bunx gaia theme
```

  </TabItem>
  <TabItem value="npm" label="npm">

```bash
npx gaia theme
```

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

```bash
pnpm dlx gaia theme
```

  </TabItem>
  <TabItem value="yarn" label="Yarn">

```bash
yarn dlx gaia theme
```

  </TabItem>
</Tabs>

This command generates a configuration file (`config.json` or `schemacolor.json`) in your project.

### Step 2: Define Your Color Scheme JSON

Edit the generated JSON file with your custom color palette. Paste your schema with structure below:

```json title="schemaColor.json"
{
  "brand": {
    "primary": "Hex/RGB",
    "primaryDark": "Hex/RGB",
    "primaryLight": "Hex/RGB",
    "secondary": "Hex/RGB",
    "accent": "Hex/RGB"
  },
  "neutral": {
    "0": "Hex/RGB",
    "50": "Hex/RGB",
    "100": "Hex/RGB",
    "200": "Hex/RGB",
    "400": "Hex/RGB",
    "600": "Hex/RGB",
    "800": "Hex/RGB",
    "900": "Hex/RGB"
  },
  "semantic": {
    "success": "Hex/RGB",
    "warning": "Hex/RGB",
    "danger": "Hex/RGB",
    "info": "Hex/RGB"
  }
}
```

### Step 3: Generate the CSS Theme (`theme-gen`)

Once you have defined your colors in the JSON file, compile it into ready-to-use CSS tokens:

<Tabs groupId="package-manager">
  <TabItem value="bun" label="Bun" default>

```bash
bunx gaia theme-gen
```

  </TabItem>
  <TabItem value="npm" label="npm">

```bash
npx gaia theme-gen
```

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

```bash
pnpm dlx gaia theme-gen
```

  </TabItem>
  <TabItem value="yarn" label="Yarn">

```bash
yarn dlx gaia theme-gen
```

  </TabItem>
</Tabs>

The CLI compiles your JSON values and writes them to `src/anima/config/schemacolor.css`, which is automatically consumed by Tailwind CSS through `index.css`.
